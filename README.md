## 📖 Tentang Proyek

Website landing page modern untuk coffee shop fiktif bernama "TitikTemu". Proyek ini mendemonstrasikan penggunaan HTML, CSS, dan JavaScript untuk membangun website yang responsif dan menarik secara visual.

## ✨ Fitur

- 🎨 **Desain Modern** - UI/UX yang premium dengan animasi halus
- 📱 **Fully Responsive** - Tampilan optimal di desktop, tablet, dan mobile
- ⚡ **Performa Optimal** - Gambar WebP dengan lazy loading
- 🍔 **Mobile Menu** - Hamburger menu yang interaktif
- 🗺️ **Google Maps Integration** - Peta lokasi terintegrasi
- 📋 **Form Reservasi** - Halaman booking dengan form lengkap

## 📄 Halaman

| Halaman          | Deskripsi                                             |
| ---------------- | ----------------------------------------------------- |
| `index.html`     | Homepage dengan hero section, menu preview, dan promo |
| `menu.html`      | Daftar lengkap menu dengan filter kategori            |
| `fasilitas.html` | Fasilitas coffee shop dengan tabel perbandingan       |
| `promo.html`     | Promo dan paket spesial                               |
| `booking.html`   | Form reservasi tempat                                 |
| `about.html`     | Tentang TitikTemu                                     |

## 🛠️ Teknologi

- **HTML5** - Struktur semantik
- **CSS3** - Styling dengan CSS Variables & Flexbox/Grid
- **JavaScript** - Interaksi dan animasi
- **Font Awesome** - Ikon
- **Google Fonts** - Typography (Outfit & Playfair Display)

## 🚀 Cara Menjalankan

1. Clone repository ini

   ```bash
   git clone https://github.com/naufalelghazy/TitikTemuWebsite.git
   ```

2. Buka file `index.html` di browser

   Atau gunakan Live Server extension di VS Code untuk development.
